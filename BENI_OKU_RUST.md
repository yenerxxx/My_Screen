# MY Screen 7.1 Professional (Rust + Liquid Glass Edition)

Python (PySide6 + Pillow + pywin32) projesinin sıfır dış bağımlılıklı, doğrudan Win32 API ve Liquid Glass UI efektli `egui` arayüzü ile yeniden yazılmış tam Rust sürümüdür.

## Derleme
1. [rustup.rs](https://rustup.rs) üzerinden Rust'ı kurun.
2. `EXE_YAP.bat` dosyasına çift tıklayın veya terminalde `cargo build --release` çalıştırın.
3. Üretilen `MY Screen 7.1 Professional.exe` dosyasını doğrudan çalıştırabilirsiniz.
